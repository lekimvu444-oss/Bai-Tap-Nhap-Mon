1. Giới thiệu

Đây là bài tập lập trình đầu tiên của tôi trong quá trình học môn Nhập môn IT.

2. Mô tả bài toán

Viết chương trình Python cho phép người dùng nhập hai số nguyên, sau đó tính tổng và hiển thị kết quả trên màn hình.

3. Công nghệ sử dụng
	•	Ngôn ngữ lập trình: Python.
	•	Nền tảng lưu trữ: GitHub.

4. Cách chạy chương trình
	•	Cài đặt Python trên máy tính.
	•	Tải file main.py về máy tính.
	•	Mở Terminal tại thư mục chứa file.
	•	Nhập lệnh:

python main.py

5. Kết quả

Ví dụ:
	•	Số thứ nhất: 5
	•	Số thứ hai: 10
	•	Tổng hai số: 15
